# 端端同步 (Duanduan Sync)

**端端同步** 是一款为思源笔记设计的局域网/本地网络同步插件，文件系统级同步引擎。您可以在多台设备之间自由同步笔记、附件、插件配置、模板等所有数据。

---

## ✨ 插件特点

- **文件系统级同步引擎**  
  - **文件系统同步**：稳健可靠，无需打开笔记本，直接基于文件哈希对比，适合全量备份和跨设备迁移。
  - **标准API同步**：速度快，利用思源自带API，适合笔记本已打开的日常使用。  （未来计划）
  
---

## 🚀 快速使用

### 1. 添加远端设备
- 在设置面板点击 **“+ 添加设备”**。
- 填写远端思源的 **IP 地址、端口（默认6806）、API Token**（在远端思源的“设置→关于→API Token”中获取）。
- 点击“测试连接”验证网络是否通畅。

### 2. 选择同步引擎和目录
- **同步引擎**：请选择“文件系统同步”（更稳健，无需笔记本打开）。
- **同步目录**：勾选您需要同步的内容（附件、插件、模板等）。

### 3. 开始同步
- 选择目标设备，点击 **“开始同步”**。
- 首次同步会计算所有文件的哈希值并缓存，后续仅同步变更的文件，速度极快。
- `注意`：同步后请手动重启笔记，才能展现同步的内容。（当前bug，下一版处理）。
- `注意`：目前处理笔记冲突的策略是以最新的为准，比如两个设备都更新了同一个笔记，同步后会以`最新`的笔记覆盖掉相比较`较旧`的笔记。
